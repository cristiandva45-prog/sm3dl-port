## CONTRATO PUBLICADO para D2/D5 (firma raíz `dx.rs`, la crea `dx_dibujo_iniciar`)
Macros definidas arriba en `raster_d3d12_prog.inc` (se incluye ANTES que D2..D5, las podéis usar):
- `DX_RS_CB(b)` = parámetro raíz `b` (0..3): CBV raíz b0..b3 (`SetGraphicsRootConstantBufferView(l, DX_RS_CB(b), dx.cb_va[b])`).
- `DX_RS_SRV` = 4: tabla de 4 SRV t0..t3 (`SetGraphicsRootDescriptorTable(l, DX_RS_SRV, gpu_srv)`), descriptores consecutivos.
- `DX_RS_SMP` = 5: tabla de 4 muestreadores s0..s3 (heap de muestreadores, `d3d_smp_reservar(4,…)`).
- Visibilidad ALL, espacio 0, flag ALLOW_INPUT_ASSEMBLER_INPUT_LAYOUT, versión 1.0. Hay que llamar `SetDescriptorHeaps` con srv_heap + smp_heap de g_d3d antes de las tablas (D5).
- `DxProg.clave` (uint64) = FNV-1a 64 de los NOMBRES de archivo DXIL realmente usados (V_x, F_x o F_UBER, G_FLIP): dos programas con el mismo bytecode comparten clave (D5: úsala en la clave de PSO). `DxProg.gs != NULL` ⇒ el PSO lleva GS.
- Bytecode: `DxEtapa.dxil/.n` → `D3D12_SHADER_BYTECODE{dxil, n}` para VS/PS/GS.

## Hecho (9 oct, hito 1) — `recomp\render\raster_d3d12_prog.inc` (respaldo `.antes_dx12_D1`)
- `dx_dibujo_iniciar`: firma raíz (6 parámetros, v1.0, espacio 0, ALL) + elige carpeta de caché con `VERSION.txt` == cadena de B
  + lee `indice.tsv` (hash→archivo, ordenado, búsqueda binaria; así el texto del modo uber → `F_UBER.dxil` y GEOM_FLIP → `G_FLIP.dxil`)
  + precarga `F_UBER.dxil`. Sin caché válida devuelve 0 (y suelta dx.rs). Idempotente.
- `etapa_compilar`: hash FNV-1a del texto (= hv/hf de la capa común), DXIL validado (DXBC firmado + parte DXIL). FS faltante →
  uber compartido (no se copia) + volcado `extraido\shaders\desconocidos_d3d12\F_<hash>.glsl`; VS/GS faltante → NULL.
  `DxEtapa.nombre` = archivo DXIL usado.
- `prog_enlazar`: valida tipos; `clave` = FNV-1a 64 de "V|F|G" (archivos). `prog_destruir` no libera etapas (son de la capa común;
  las reusa) y limpia `dx.prog` si apuntaba ahí. `prog_cargar_cache` = NULL sin rechazo; `prog_guardar_cache` no-op (DXIL ya en
  disco, PSO lo cachea `d3d_pso_obtener`). `prog_usar` = `dx.prog`.
